{# The board, and the one place the open task's id is written down. Nothing on this page subscribes to a broadcast, so the table carries no `hx-*` of its own. It is only ever a reply, swapped in band by a pick or an advance. The hidden input is what makes the lazy panels possible. An `intersect` carries no event to read an id out of, and a panel that was hidden when the pick happened never heard one either — so the id has to sit somewhere both paths can reach, and that is the page. Its being *current* by the time anything reads it is the routes' job: they broadcast with `hx_trigger_after_swap`, which fires after this table is in the document rather than before. It is written down only when there *is* an id, and that is not tidiness. An `hx-include` sends whatever it selects, so an input rendered `value=""` on the cold page sends `task_id=`, and an empty string is not an integer: the first panel to open on a fresh page answers 422 before anyone has picked anything.
