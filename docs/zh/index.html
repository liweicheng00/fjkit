給 FastAPI 的快速 UI

給 FastAPI 的頁面、表格、表單、導覽與 htmx 局部更新，以 Jinja macro 寫在路由旁邊。

主要特色

零建置

沒有 package.json、沒有 node_modules、沒有 watcher。stylesheet 在 fjkit 發佈時編譯，不在你的 app 執行時編譯。

顏色只有一個開關

每個顏色都是 token。換品牌是一份 stylesheet，狀態色不跟著變，所以綠色仍然代表完成。

htmx 端點同時是 JSON API

渲染 partial 的路由對 htmx 回 HTML，對其他呼叫者回 response model 的 JSON。

01

開始使用

安裝一個套件，寫一個 handler 與一份模板，執行 app。

需要 Python 3.13 以上。

uv add fjkit
from pathlib import Path

from fastapi import FastAPI
from fjkit import FjkitConfig, mount_fjkit, render
from pydantic import BaseModel

app = FastAPI()
mount_fjkit(app, FjkitConfig(template_dir=Path(__file__).parent / "templates"))


class Overview(BaseModel):
    done: int


@app.get("/")
@render("overview.html")
def overview() -> Overview:
    return Overview(done=18)

mount_fjkit 供應 stylesheet 與內附的 JavaScript，並建立 Jinja environment。 @render 寫在 @app.get 下方，把回傳 model 的欄位交給模板。 

{% extends "ui/shell.html" %}
{% from "ui/layout.html" import page_header, grid %}
{% from "ui/data.html" import stat %}

{% block content %}
  {{ page_header("Overview", "How the board is doing") }}
  {% call grid(cols=4) %}
    {{ stat("Done", done, tone="success", icon_name="check") }}
  {% endcall %}
{% endblock %}
uv run fastapi dev app/main.py

開啟 http://127.0.0.1:8000。頁面有 header、深色模式切換與一張統計卡。 模板裡沒有 CSS class，也沒有顏色：macro 接受具名選項，例如 tone="success"， 由內附的 stylesheet 負責呈現。

把 uv run fjkit check app/templates 加進 CI。模板使用詞彙表以外的 class 或顏色時，它會失敗。

02

給誰用

會寫後端、需要一套介面、不想碰前端工具鏈的人。

適用對象：已經在寫 FastAPI，需要導覽、深色模式、一張可篩選的表格，以及一個會驗證的表單。 若要使用 React、Vue 或 Svelte，請直接用它們：fjkit 在伺服器端渲染，沒有前端元件模型。

預期成本

第一頁

約二十行，如 01 所示，沒有建置步驟

一個後台畫面

列表、篩選、新增表單與 htmx 更新，不寫 CSS，也不寫 JavaScript

03

wheel 裡裝了什麼

一個 wheel、兩個執行期依賴，不需要自行編譯任何東西。

套件裡帶的

templates/ui/

macro：版面、按鈕、資料、表單、表格、分頁、導覽、側欄、回饋、圖示與文件外殼

static/dist/fjkit-<pack>.css

編譯好的 stylesheet，每個風格包一份。234 KB 原始、23.9 KB gzip；超過 28 KB 時 build 失敗。一頁只載一份。

static/vendor/

htmx 與 Basecoat 的 JavaScript，版本釘死，直接從套件裡供應

1,767 個圖示

Lucide，按名字內嵌。沒有 icon font、沒有 sprite 請求、執行期沒有 JS。

你會用到的全部介面

FjkitConfig、mount_fjkit

接線，每支 app 一次

@render

指名模板；handler 只回資料

執行期依賴：FastAPI 與 Jinja2。
