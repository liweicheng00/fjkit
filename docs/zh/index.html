給 FastAPI 的快速 UI

把 Jinja、Tailwind CSS 與 shadcn 風格元件整合起來，給 FastAPI 用。

主要特色

零建置

沒有 package.json、沒有 node_modules、沒有 watcher。stylesheet 在 fjkit 發佈時就編譯好了，不是在你的 app 執行時。

一個顏色旋鈕

每個顏色都是 token。換品牌是改一個檔案，而且改完綠色仍然代表完成。

掛在你現有的 API 上

每一個 htmx 端點都會用 JSON 回應 curl。同一條路由、同一個 handler、同一個回傳標註。

01

給誰用

會寫後端、需要一個像樣的介面、又不想碰前端工具鏈的人。

你已經會寫 FastAPI。你需要導覽、深色模式、一張可篩選的表格，以及一個會驗證的表單。 這是給你的。

如果你要帶 React、Vue 或 Svelte 進來，那這一層就選錯了。這是一個決定，不是一個缺口。

它應該花你多少

第一頁

大約二十行 Python 就有導覽與深色模式，而且沒有建置步驟

一個後台畫面

列表、篩選、新增表單與 htmx 更新，一個下午。不寫 CSS，也不寫 JavaScript。

換品牌

一份覆寫 token 的 stylesheet，掛在 kit 的後面

升級

改一個版本號。stylesheet 在 wheel 裡，不在你的 repo 裡。

02

wheel 裡裝了什麼

一個 wheel、兩個執行期依賴，沒有任何東西要你自己編譯。

套件裡帶的

templates/ui/

那些 macro：版面、按鈕、資料、表單、表格、分頁、導覽、側欄、回饋、圖示，以及文件外殼

static/dist/fjkit-<pack>.css

編譯好的 stylesheet，每個風格包一份。234 KB 原始、23.9 KB gzip，在 build 自己守著的 28 KB 預算內。一頁只載一份。

static/vendor/

htmx 與 Basecoat 的 JavaScript，版本釘死，直接從套件裡供應

1,767 個圖示

Lucide，按名字內嵌。沒有 icon font、沒有 sprite 請求、執行期沒有 JS。

你會碰到的全部表面

FjkitConfig、mount_fjkit

接線，每支 app 一次

@render

在裝飾器上指名模板；handler 只回資料

fjkit check

詞彙表關卡。放進你的 CI。

fjkit eject

逃生口：把元件複製進你的 app 再改

需求：Python 3.13 以上，以及兩個執行期依賴——FastAPI 與 Jinja2。要加第三個，需要一個到 目前為止還沒有人提得出來的理由。
