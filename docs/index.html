A Fast UI for FastAPI

An integration of Jinja, Tailwind CSS and shadcn-style components, for FastAPI.

The key features are:

No build step

No package.json, no node_modules, no watcher. The stylesheet is compiled when fjkit is released, not when your app runs.

One colour knob

Every colour is a token. Rebranding is one file, and green still means done afterwards.

Mounts on your existing API

Every htmx endpoint answers curl with JSON. Same route, same handler, same return annotation.

01

Who it is for

A back-end developer who needs a real interface and no front-end toolchain.

You already write FastAPI. You need navigation, dark mode, a filterable table and a form that validates. This is for you.

If you are bringing React, Vue or Svelte, this is the wrong layer. That is a decision, not a gap.

What it should cost you

a first page

navigation and dark mode in about twenty lines of Python, with no build step

an admin screen

list, filters, a create form and htmx updates in an afternoon. No CSS, no JavaScript.

a rebrand

one stylesheet of token overrides, loaded after the kit's

an upgrade

a version bump. The stylesheet lives in the wheel, not in your repository.

02

What ships in the wheel

One wheel, two runtime dependencies, and nothing for you to compile.

Shipped in the package

templates/ui/

the macros: layout, buttons, data, forms, tables, tabs, navigation, sidebar, feedback, icons, and the document shell

static/dist/fjkit-<pack>.css

the compiled stylesheet, one per style pack. 234 KB raw, 23.9 KB gzip, under a 28 KB budget the build enforces. A page loads one.

static/vendor/

htmx and Basecoat's JavaScript, pinned and served out of the package

1,767 icons

Lucide, inlined by name. No icon font, no sprite request, no runtime JS.

The whole surface you touch

FjkitConfig, mount_fjkit

the wiring, once per app

@render

name a template on the decorator; the handler returns data

fjkit check

the vocabulary gate. Run it in your CI.

fjkit eject

the escape hatch: copy a component into your app and edit it

Requirements: Python 3.13 or newer, and two runtime dependencies — FastAPI and Jinja2. A third one needs an argument nobody has made yet.
