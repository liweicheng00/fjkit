columns 是一串 dict：label，需要時再加 align、 width、sort、sort_url 或 select。 rows 則決定這支 macro 要渲染你的內容還是空狀態。 它收下一份自己並不迭代的 rows 就是為了這件事：呼叫端不必重寫 if-rows-else， 也不會有頁面出貨一張只剩表頭的表格。

重複的 row 是你迴圈裡的一次 macro 呼叫。在那裡用 {% raw %}{% include %}{% endraw %} 等於每一輪多一次模板查找與一份新的 context， 那正是「上手」那一頁的 benchmark 量到的差距。

帶了 sort_url 的欄位會變成可排序表頭，pagination 則放在表格底下。 兩者都不自己組網址：query string 歸路由管，因為只有它知道現在開著哪些篩選。 兩者渲染的都是真的 href，再由 target= 疊上 htmx swap—— 排序與頁碼是一張清單裡最常被收進書籤的兩件事，所以關掉 JavaScript 也必須還在。
