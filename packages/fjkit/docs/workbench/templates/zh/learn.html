接下來是 fjkit 那一半。partial 就是名字以底線開頭的模板：它不 extends 外殼， 自己宣告 import，並且把自己包在「會被換掉的那個元素」裡。整頁用 {% raw %}{% include %}{% endraw %} 把它放進去；每個 htmx 端點則是光禿禿地回它。

這就是為什麼 fjkit app 裡沒有「更新那一列」這條程式路徑。每一次異動都重新渲染整塊板子的 partial 再換進去——一份「板子長什麼樣」的定義，第一次上色用它，之後每個請求也用它。 真正的檔案在 repo 的 examples/board/app/templates/tasks/。

第 02 課說這段交換裡沒有 JSON——就 swap 本身而言是對的。但看一眼 handler 真正回傳的東西： 是一個 BoardResponse，不是一串 HTML。把前者變成後者的是 @render；而當呼叫端不是一個在等標記的瀏覽器時，就沒有東西可以渲染進去， model 便直接以 JSON 送出。
