{# The request diagram — one SVG, both languages. Every word in it comes from `t.diagram`, which `build.py` carries per language. Copying the figure to translate it would mean maintaining two sets of coordinates, and the second set would be the one that goes stale. No classes anywhere in it: colours and sizes are SVG presentation attributes, and the stage lighting is driven by `data-lit` on each group, which learn.js flips from real htmx events. That keeps the figure inside the closed vocabulary — an SVG is one of the few places where a page legitimately has no component to reach for, and attributes are how it stays honest. #}
