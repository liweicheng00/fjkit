An app replaces this by writing its own `errors/page.html`. The app's template directory is searched before the kit's, so a file at this path wins, the way `fjkit eject` works; there is no separate "custom error page" setting to find. An app doing that usually wants `{% extends "base.html" %}` so the page keeps its nav. This one extends the shell directly, because the kit cannot know what an app called its base.
