{# attrs() — render pass-through HTML attributes from macro kwargs. Underscores become dashes, so callers write Python-ish keywords and get HTML: {{ button("Save", hx_post="/tasks", hx_target="#board") }} -> `true` renders a bare boolean attribute, `none`/`false` render nothing. This is the seam that keeps htmx out of the macro definitions: no component needs to know an hx-* attribute exists, and adding a new one never requires touching fjkit. #} {%- macro attrs(mapping) -%} {%- for key, value in mapping.items() if value is not none and value is not false -%} {{ " " }}{{ key.replace("_", "-") }}{% if value is not true %}="{{ value }}"{% endif %} {%- endfor -%} {%- endmacro -%}
